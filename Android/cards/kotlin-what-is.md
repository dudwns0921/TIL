# Kotlin이란


- JetBrains(IntelliJ 제작사)가 만든 언어. JVM 위에서 동작, Java와 100% 상호운용.
- 포지션 비유: TS가 "JS + 타입 시스템"이라면, Kotlin은 "Java + 엄격한 null 안전성 + 간결한 문법"에 가까움. `String`과 `String?`을 타입 레벨에서 구분해 null 미처리 코드는 컴파일 자체가 안 됨.
- 2019년부터 Google 공식 안드로이드 언어 (Java 대체).
- 서버(Ktor/Spring), 웹(Kotlin/JS), iOS(Kotlin Multiplatform)로도 확장되지만 이 노트에서는 안드로이드 맥락에 집중.
